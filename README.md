Claude Code を Headroom 0.42.0 なし（A）とあり（B）で実行し、[usememos/memos](https://github.com/usememos/memos) のマージ済みの修正を再現させて比べた結果です。1回の入力につき1セッションを使いました。

## 結論

3回ずつ実行した `wrap` の12組では、Bが安かったのは6組で、費用は平均-1.8%でした。総トークンは-11.4%でした。組ごとの費用の増減は-23.7%〜+42.7%と大きく、差は誤差の範囲を超えていません。

## 比較するときの注意

- `wrap-first`、`wrap-second` の1回目、`wrap-third` は同じ A-1 と比べています。
- `first`、`second`、`third` はBを `headroom proxy` 経由、`wrap-*` は `headroom wrap claude` で実行しました。
- `wrap-first` のBは、Serenaが起動時に落ちた状態の結果です。
- `wrap-third` はBでSerenaを使いやすくしましたが、呼び出しは0回でした。

## ファイル

`results/<実行名>/summary.md` が実行ごとの要約です。各試行の値は `results/<実行名>/<ケース>/<条件>-<回>/score.json`、Claudeの変更は同じ場所の `changes.diff` にあります。

生ログは個人情報を含むため、このリポジトリには入れていません。
